# Zapret Hub 1.0.2 — новый движок

**Главное в этой версии: программа переписана с Python + PySide6 на
Electron + React + TypeScript.** Интерфейс перерисован заново, а логика обхода
перенесена один в один: те же четыре раздела, те же настройки, то же поведение
компонентов. Плюс исправлен ряд ошибок, накопившихся в прежней версии.

---

## 🆕 Что нового

- **Новое окно.** Тёмная тема на единой палитре, своя верхняя полоса с кнопками,
  боковое меню, четыре раздела: Главная, Компоненты, Диагностика, Настройки.
- **Автоподбор стратегии.** По очереди поднимается каждый `general*.bat` и
  проверяет сайты теми же тестами, что и пакет: HEAD-запрос по HTTP/1.1, TLS 1.2,
  TLS 1.3 и ping. Каждая проверка — отдельный отрезок в графике (зелёный —
  быстро, жёлтый — медленно, красный — нет ответа). После прогона стратегии
  выстраиваются по результату, и **лучшая становится текущей сама** — даже если
  прогон остановили вручную.
- **Выбор стратегии одной кнопкой.** Щелчок по кнопке раскрывает список всех
  стратегий пакета; список не тащит за собой страницу.
- **Компоненты ставятся из программы.** Нет zapret или tg-ws-proxy — Hub сам
  предложит скачать их с GitHub и покажет ход дела с настоящими процентами.
- **Окно ошибки.** Всё, что не получилось, показывается отдельным окном с текстом
  отказа и кнопкой «Скопировать» — вместо молчащего журнала.
- **Одна мастер-кнопка** включает и гасит оба обхода сразу; отдельные карточки
  показывают состояние, текущую стратегию, Game Filter, IPSet и время работы.
- **Трей и автозапуск.** Запись в `HKCU\...\Run` с ключом `--tray`, «Запускать
  свёрнутым», «Сворачивать в трей вместо закрытия».
- **Русский и английский** — переключаются в настройках.

## 🐞 Что исправлено

- **«Компонент не установлен» больше не врёт.** Программа ищет пакет и во
  вложенных папках (когда архив распакован вместе с папкой-контейнером) и считает
  установленным работающий компонент.
- **Сломанный компонент не отнимает интернет.** Раньше отказ одного обхода мог
  уронить связь; теперь остановка и сбой изолированы, сеть остаётся при пользователе.
- **Пользовательские списки и настройки выживают при обновлении.** Всё, что лежит
  в `lists/`, сохраняется перед распаковкой нового пакета и возвращается на место.
- **Обновление программы** берёт версию из тега релиза и ищет установщик по
  расширению `.exe` — в релизе на GitHub достаточно одного файла, никаких
  `latest.yml` и `.blockmap`.
- **Удаление программы убирает её данные.** Деинсталлятор чистит
  `%APPDATA%\ZapretHub` — настройки, журналы и скачанные компоненты.
- **Программа перестала есть процессор.** Убран опрос дерева процессов через
  PowerShell каждые полсекунды (это было 120 запусков в минуту на компонент), а
  интерфейс больше не перерисовывает всё окно, когда ничего не изменилось.
- **Ключ `--tray` из автозапуска наконец работает**: при входе в Windows
  программа поднимается в трей, а не раскрывает окно на весь экран.
- Папкам данных выдаются права для группы «Пользователи» — кнопки «Открыть папку»
  больше не молчат.

## ⬇️ Как обновиться

1. Скачать **`ZapretHub-1.0.2-Setup.exe`** из этого релиза.
2. Запустить и разрешить права администратора — они нужны `winws.exe`: он
   работает через WinDivert.
3. Если стоит прежняя версия на Python — удалите её папку вручную. Новая
   программа ставится в `C:\Program Files\Zapret Hub` и держит свои данные в
   `%APPDATA%\ZapretHub`, так что старая копия ей не мешает.
4. Компоненты (`zapret-discord-youtube`, `tg-ws-proxy`) программа скачает сама
   при первом запуске, если их ещё нет.

## ⚠️ Известные ограничения

- Только Windows 10/11, x64.
- Нужны права администратора: без них `winws.exe` не запускается.
- На диске около 230 МБ — это вес движка (Chromium и Node).
- Если в системе стоит служба Windows `zapret` (её ставит `service.bat` пакета),
  Hub предупредит и предложит её удалить.
